# Main-results reproducibility guide

## Purpose and supported execution

The tested route starts with the deposited patient-level predictions and recomputes the main results. It does not retrain the nine encoders/MIL models, regenerate slide patches, or reproduce all exploratory figures. Use the root `reproduce.py` command in README. It accepts `--output-dir PATH` and can be launched from another working directory.

`requirements.txt` specifies the supported NumPy range. `environment_recompute.json` records the actual Python and NumPy versions used for this release's verification, not the historical GPU-training environment. No R installation is required for the main entry point. The optional PH-diagnostic script uses R 4.5.2 and survival 3.8-3 as recorded in its own README; it is outside this command's execution scope.

## Inputs and outputs

| Input | Role |
|---|---|
| `gx1_posthoc_v1_20261025/outputs/grading_predictions.csv` | 3,780 ensemble records: nine encoders × (300 Korean + 120 Scottish patients) |
| `grading_predictions_per_run.csv` in the same directory | 40,500 records: nine encoders × (300 × five Korean seed predictions + 120 × 25 Scottish seed/fold predictions) |
| `korea_split.csv` in the same directory | Locked patient roles for all five folds; each Korean patient belongs to one outer test fold |
| `recurrence_he_risk.csv` in the same directory | Existing two-encoder direct-recurrence predictions used by the archived verifier |
| Root study `RESULTS.json` files and `POSTHOC_RESULTS.json` | Reference values against which recomputations are checked |
| `reproduction_inputs.sha256.json` | Byte hashes of this public edition's numerical inputs and verifier/configuration |

Generated files: `VERIFY_REPORT.md` (93 numerical/structural checks), `main_grading_results.csv` (AUC and four-class accuracy), `MAIN_RESULTS.json` (key results including Holm P and frozen combined C), `RUN_RECEIPT.json` (environment and pass status), and verifier stdout. Input copies in the output folder allow the historical verifier to write its report without modifying source data.

The original verifier reports failures in Markdown but does not return a failed process status. The new entry point explicitly checks its PASS/FAIL report and exits non-zero on a failed check. Input hashes are checked before calculations. Tolerances follow the archived verifier: generally 1e-3 for AUC/C/QWK and 0.01 for hazard ratios because exported probabilities have six decimal places. Three additional frozen-model C-index comparisons use 1e-3 tolerance. Bootstrap confidence intervals are archived estimates and are not regenerated by this entry point. The Holm P values are recomputed from nine Cox tests within each cohort, with numeric ISUP adjustment; this is the post hoc multiplicity sensitivity analysis, not a new prespecified endpoint.

## Original main training protocol

The authoritative configuration is `source_reference/grade_ext_v1_20261022/config.json`. Nine encoders × five seeds × five outer folds produced 225 training runs. Within each outer fold, the previously designated training and validation patients were pooled; that fold's test patients remained excluded. Scotland never entered training. Forty fixed epochs were used, with the last epoch retained; external performance was not used for stopping.

| Setting | Value |
|---|---|
| Encoder | Frozen; each patch feature L2-normalised |
| MIL | Linear 256 + ReLU + dropout 0.25; gated attention hidden 128; four output classes |
| Sampling | Up to 2,048 patches per patient per epoch, without replacement; all patches when fewer |
| Optimisation | AdamW, learning rate 1e-4, weight decay 1e-4; accumulate four patients; clip norm 5 |
| Loss | Cross-entropy weighted by n_train / (4 × class count), using training cases only |
| Seeds | Index 0–4; model seed 20261026 + 100 × seed index + fold |
| Inference | All retained patches, computed in chunks of 4,096 |
| Ensemble | Korea: mean of five out-of-fold seed probabilities; Scotland: mean of 25 seed/fold probabilities |
| High-grade score | P(ISUP 3) + P(ISUP 4) |
| Continuous AI grade | 1×P1 + 2×P2 + 3×P3 + 4×P4 |
| Recurrence | Exclude five Korean zero-time cases; administrative censoring at 84 months |

The continuous grade is computed after probability prediction. Attention-additive logits do not make expected slide grade an attention-weighted average of patch grades. Models compare with the published database labels, not independent medical validation of those labels.

## Source map for reconstruction from images

| Step | Included reference source | Additional inputs required |
|---|---|---|
| CZI reading and QC | `source_reference/feature_extraction/hpc_bib_phase1/czi_pilot_v2.py`, `full_patch_qc.py` | Source WSIs, matching manifests and download receipts |
| Retained-coordinate export | `export_qc_primary_v1.py`, `export_scotland_primary_v1.py` in that directory | Per-patch QC results and the Scottish cohort's technical exclusions |
| Nine-encoder extraction | `extract_nine_korea.py`; `source_reference/feature_extraction/scotland_nine_extract_v1_20261021/extract_nine_scotland.py`; A6000 reference source in the sibling directory | Retained coordinates, exact model weights/transforms, runtime dependencies and local paths |
| Main training | `source_reference/grade_ext_v1_20261022/{common,train,check,lock,evaluate}.py` | Complete feature arrays, manifests, folds, new valid locks and technical-check records for the adapted edition |
| Export to this release's tables | `source_reference/gx1_posthoc_v1_20261025/export_predictions.py` | Completed run prediction files |
| Frozen combined model | `source_reference/gx1_posthoc_v1_20261025/posthoc.py` | Exported grade probabilities plus clinical outcomes; a standalone point-estimate recomputation is included in `reproduce.py` |

Native QC uses 128 µm fields with candidate tissue fraction 0.10. Its source distinguishes nearly blank/black rejection, unscanned gaps, and review flags for sparse tissue, black edges and low focus. The focus threshold is a heuristic, not a pathology diagnosis. All encoders must use exactly the same retained coordinates. Consult the Scottish export source for its additional artefact exclusions rather than silently applying only the Korean export.

The training source preserves a lock-gated workflow. Do not copy historical PASS files or disable assertions to make an adapted run start. A new attempt requires a separate working directory, adapted paths, verified input hashes, regenerated locks and successful technical checks. Source-reference labels/provenance hashes may refer to original bytes before path/line-ending normalisation; the release's hashes do not certify a new GPU run. The current release does not provide a tested turnkey command for original-slide retraining.

## Availability limits and study timing

Available: exported per-case/per-run predictions, clinical derivatives, fold assignments, source reference, formal configuration, QC summaries and result references. Not included: complete retained-coordinate arrays, cached feature matrices, all trained checkpoints and raw historical execution receipts. The derived run-summary CSVs are not substitutes for raw receipts. GPU runtime/weight provenance must be re-established before claiming exact raw-image retraining; no versions are guessed here.

Earlier exploratory results existed before the formal protocol was internally locked. Neither internal locks nor this public release establish prospective public preregistration. The protocol/result snapshots are historical evidence; the manuscript's qualifications govern interpretation.
