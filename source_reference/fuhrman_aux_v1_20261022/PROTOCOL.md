# 方向 3：Fuhrman 分级作辅助监督（fuhrman_aux_v1_20261022）

**要回答的问题：** 训练 ISUP 分级模型时，把同一例的 Fuhrman 分级作为辅助任务一起学，能不能让模型从 HE 图像里学到更多、从而更好地区分 ISUP 1/2 级？还是说所谓的"帮助"只来自两种分级在统计上的相关？

代码、本文件和 `CAMPAIGN.json` 在任何正式结果出来之前锁定（`LOCK.json`）。锁定后的任何改动都要另建版本目录，并且只能在看到正式结果之前做。

## 1. 数据与标签

| 项目 | 内容 |
|---|---|
| 病例 | 韩国 300 例（主分析池），全部使用 |
| 标签 | **以数据库公开临床表为准**（BioImage Archive S-BIAD2452 `Korean clinical Data.xlsx`，sha256 `0c600a87…`；用户 2026-10-21 决定）。原论文 Table 1 与表格的不一致只在文中披露。`make_labels.py` 把表格转成 `inputs/korea_labels.csv`（病例号、ISUP、Fuhrman）；ISUP 必须与分析池 manifest 及五折表一致，否则拒绝运行 |
| 主任务 | ISUP 1–4 四级（y = ISUP − 1） |
| 辅助任务 | Fuhrman 两档：1–2 级 → 0，3–4 级 → 1（Fuhrman 1 级只有 2 例，事先合并；交接文档 9.2 第 5 条） |
| 划分 | 已锁定的五折外层测试归属。第 f 折：训练集 = 该折的 train + val（240 例），测试集 = 该折的 60 例。每例只在自己的测试折被预测一次 |
| 特征 | 冻结编码器的全片特征 `features/nine_encoder_full_v1_20261010/<病例>/<编码器>.npy`，sha256 与 complete.json 一致，镜像上需有 .verified 标记 |

## 2. 三个臂

| 臂 | 损失 | 作用 |
|---|---|---|
| **A** | 只有 ISUP 交叉熵 | 基线 |
| **B** | ISUP 交叉熵 + 0.5 × Fuhrman 交叉熵（每例自己的 Fuhrman） | 待检验的方法 |
| **C** | ISUP 交叉熵 + 0.5 × Fuhrman 交叉熵（**在每个 ISUP 级内部打乱**训练集的 Fuhrman 标签） | 对照：保留 ISUP 与 Fuhrman 的统计关联和各类数量，切断 Fuhrman 与这一例图像的对应 |

- 只有 B 同时胜过 A 和 C，才能说 Fuhrman 让模型从图像里学到了东西；如果 C 与 B 一样好，增益只是标签相关性带来的。
- C 的打乱对每个种子、每折固定（由种子、折、ISUP 级派生），每个 ISUP 级内的 Fuhrman 两档数量不变。
- 辅助任务权重 0.5 事先固定，不调。
- 三个臂用同一个模型（两个输出头都建），初始化相同；A 的辅助头不参与训练，ISUP 输出也不依赖它。

## 3. 训练（每次运行 = 编码器 × 臂 × 种子 × 折）

| 项目 | 锁定值 |
|---|---|
| 编码器 | **Phikon-v2（主）**、UNI（重复验证），均 1024 维、冻结 |
| 模型 | 与既往四级模型相同的 gated ABMIL：每个图块 L2 归一化 → 线性 256 + ReLU + dropout 0.25 → 门控注意力 128 → ISUP 头（4 类）；辅助头（2 类）接在同一个池化表示上 |
| 每轮抽样 | 每例 2,048 个图块（不足全取，不放回）；三个臂、两个编码器在同一种子、折、轮、病例下抽到相同的图块 |
| 轮数 | 固定 40 轮，取最后一轮，不早停、不选模 |
| 优化 | AdamW，lr 1e-4，weight decay 1e-4；每 4 例累积梯度；梯度裁剪 5；每个头各自的类别权重 n/(K × 该类例数)，按训练集计算 |
| 种子 | 5 个（0–4）。模型初始化种子 = 20261023 + 100 × 种子 + 折；抽样与顺序由 (20261023, 种子, 折, 轮, 病例) 的 sha256 派生 |
| 测试 | 每例全部图块，整例统一注意力（分块编码、全局 softmax），输出 4 级 ISUP 概率 |
| 平台 | lab-a6000 的 RTX A6000；确定性算法、关闭 TF32；只允许同平台续跑 |
| 运行数 | 2 编码器 × 3 臂 × 5 种子 × 5 折 = 150 |

训练过程只记录训练损失，不计算、不打印任何测试成绩。

## 4. 技术检查（check.py；不看任何成绩）

- 病例事先规定：第 0 折训练集里每个 ISUP 级按病例号取前 2 例，共 8 例。
- 对 2 编码器 × 3 臂各做：2 轮不中断训练；同样训练、第 1 轮后暂停并在**新进程、另一张卡**上续跑；两者的模型、优化器、随机数状态、训练历史和预测必须逐位相同。分块 4096、整包、777 三种算法的 ISUP 概率最大差 ≤ 1e-5。用到的 ISUP 标签与数据库标签文件一致；B 的辅助标签就是每例自己的 Fuhrman 两档；C 的辅助标签是同一 ISUP 级内的重排；A 没有辅助标签。
- 结果写入 `CHECK_PASS.json`。正式运行要求它是当前代码、当前平台的 PASS，并证明了跨卡续跑。被杀、超时或暂时性 GPU 问题不记录（退出 74/75），只有比较不一致才记 FAIL。

## 5. 分析（evaluate.py，150 次运行全部完成后运行一次）

前提：150 份回执齐全、哈希一致，属于同一代码签名、同一配置、同一平台；每个编码器 × 臂 × 种子的 OOF 恰好覆盖 300 例各一次；同一编码器的所有运行读到的特征字节相同。

- **主要指标：G1 对 G2 的 AUC**：在 240 例 ISUP 1–2 病例中，以 P(G2) / (P(G1) + P(G2)) 为分数（P 为 5 个种子平均后的 ISUP 概率），合并 OOF 计算。
- Δ(B−A)、Δ(B−C)、Δ(C−A)，以及每个种子各自的差。
- 95% 区间：按 ISUP 等级分层的病例 bootstrap，2,000 次，各臂用同一组重抽样（配对），百分位区间；只作报告，不参与判定。
- 次要指标（只报告）：高/低级 AUC（P(G3)+P(G4)）、四级 QWK、Macro-F1、准确率；B、C 的辅助头对测试集 Fuhrman 1–2 对 3–4 的 AUC（测试集 Fuhrman 只在分析时读取）。

## 6. 决策规则（只看主编码器 Phikon-v2；UNI 作为重复验证报告）

| 结果 | 条件 |
|---|---|
| **阳性** | Δ(B−A) ≥ 0.02，5 个种子中至少 4 个 Δ(B−A) > 0；并且 Δ(B−C) ≥ 0.01，5 个种子中至少 4 个 Δ(B−C) > 0（增益中要有明确的、来自图像对应关系的部分，不能只是标签相关性） |
| **阴性** | Δ(B−A) ≤ 0，或 Δ(B−C) ≤ 0（增益可以用标签相关性解释，不是图像学习的收益） |
| **不明确** | 其他情况 |

阈值比较的都是点估计。结果写入 `RESULTS.json` 和 `RESULTS.md`，原样报告，阴性也报告。韩国 OOF 此前已用于多轮分析，本试验属于探索性研究；若为阳性，下一步在苏格兰队列上用同样锁定的比较确认（苏格兰的 ISUP 与 Fuhrman 也取自数据库表）。
