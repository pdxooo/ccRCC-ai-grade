# Source-code reference edition

This directory includes the original study's extraction, training, evaluation, auxiliary-analysis and figure-building source, with machine-account path prefixes replaced by generic /data paths. The source_adaptation_manifest.json records original file-byte SHA-256 values and reference-edition SHA-256 values after UTF-8/LF normalisation enforced by .gitattributes. Redaction changes code hashes; original LOCK.json and CHECK_PASS.json records are deliberately not redistributed as if they validated these adapted files. Signature strings appearing in historical result summaries are historical metadata, not approvals for this edition.

The changes are path redactions, not new training or a reanalysis. Python files were syntax-checked. GPU training, slide decoding and complete end-to-end execution of this reference edition have NOT been tested. Existing cached features, all retained coordinate arrays, trained checkpoints and raw run receipts are not included. Download the source slides and third-party encoder weights from their providers under their licences; adapt paths and prepare the required inputs before running any extraction or training script. If using the original lock-gated execution workflow, generate new locks and execute its checks for the new configuration; do not copy historical PASS/signature records to bypass checks.

For a tested, standalone recomputation of the main reported metrics, use the verifier at ../gx1_posthoc_v1_20261025/verify_from_predictions.py. That verifier needs only the exported predictions and NumPy and does not depend on these training-source files.

Clinical tables are derivatives of the public study data. Public patient IDs identify study records, not names. This public repository does not change the terms of third-party data, software or pretrained weights. The archived source datasets specify CC0; original code has no selected open-source licence. See ../DATA_SOURCES.json and ../REPRODUCIBILITY.md.
