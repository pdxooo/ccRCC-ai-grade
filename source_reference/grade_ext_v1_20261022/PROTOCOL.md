# ISUP 分级外部验证与 AI 分级分数（grade_ext_v1_20261022，调度器名 gx1）

**要回答的两个问题：**
1. 用韩国队列训练的 HE 分级模型，在苏格兰队列上能否区分高级别（ISUP 3–4）和低级别（ISUP 1–2）？
2. 模型给出的连续"AI 分级分数"（期望级别）预测复发是否优于病理医生的 ISUP 分级，并在 ISUP 之外提供额外信息？

同时做 9 个编码器的对比（6 个病理基础模型、3 个 ImageNet 模型）。代码、本文件和 `CAMPAIGN.json` 在任何正式结果出来之前锁定（`LOCK.json`）。判定阈值（config.json，sha256 `857c37b3…`）写于 2026-10-22 17:16，早于方向 3（fuhrman_aux_v1）出结果，此后不再改动。

## 2. 模型

与既往 4 级模型（mil_first_round_v2；方向 3 的 A 组）相同：每个图块 L2 归一化 → 线性 256 + ReLU + dropout 0.25 → 门控注意力 128 → 4 类。类别加权交叉熵（权重 = n / (4 × 该级例数)）。每例每轮 2,048 个图块；固定 40 轮，取最后一轮；AdamW lr 1e-4、weight decay 1e-4；每 4 例累积梯度；梯度裁剪 5。

种子 5 个，初始化种子 = 20261026 + 100 × 种子 + 折。共 9 编码器 × 5 种子 × 5 折 = 225 次运行，每次预测本折韩国测试病例和全部苏格兰病例。

- 汇总：韩国每例取 5 个种子的平均概率（折外）；苏格兰每例取 25 个模型的平均概率。
- **AI 分级分数** = Σₖ k·P(k)，为 1–4 之间的连续值。

训练只记录训练损失，不计算任何测试成绩。

## 3. 指标

- **主要指标 1：** 苏格兰高低级别 AUC，评分 P(3) + P(4)；95% 区间用按 ISUP 级分层的病例 bootstrap（2,000 次）。
- **主要指标 2：** 苏格兰复发 ΔC = C(AI 分级分数) − C(ISUP 分级)。Harrell C 与 surv1 相同：同一时间一例复发、一例未复发也算可比；风险并列计 0.5。95% 区间用病例 bootstrap。同时在苏格兰拟合 Cox(ISUP + AI 分级分数)，ISUP 按 1–4 连续处理，报告 AI 每升高 1 级的 HR 及 Wald 95% 区间。
  - ISUP 只有 4 档，并列很多，连续分数可能单凭"打破并列"就提高 C；所以判定还要求 AI 在 ISUP 之外的 HR 显著，并报告同一 ISUP 级内的 C 指数。
- **次要指标（只报告）：**
  - G1 对 G2 AUC；四级 argmax 的二次加权 kappa、准确率、宏 F1；
  - 韩国折外的同一套结果；
  - Fuhrman 的 C 指数；同一 ISUP 级内的 C 指数（只比较同级病例对）；Cox(Leibovich + AI) 中 AI 的 HR；
  - 低级别（ISUP 1–2）病例中 AI 分级分数的 C 指数，以及按本队列中位数分高低组的 log-rank；
  - 每个种子的结果（高低级别 AUC、G1/G2 AUC、AI 分级分数的 C 指数）；
  - 9 个编码器的完整对比表；只用韩国折外高低级别 AUC 选出的编码器在苏格兰的结果；病理基础模型与 ImageNet 模型在苏格兰的平均 AUC。

## 4. 判定（只看主编码器 Phikon-v2）

| 判定 | 结果 | 条件 |
|---|---|---|
| 1. 分级外推 | **成功** | 苏格兰高低级别 AUC ≥ 0.80，且 95% 区间下限 > 0.70 |
| | **失败** | AUC < 0.70 |
| | **不明确** | 其他情况 |
| 2. AI 分级分数 | **阳性** | 苏格兰 ΔC ≥ 0.02，且 Cox(ISUP + AI) 中 AI 的 HR 95% 区间下限 > 1 |
| | **阴性** | ΔC ≤ 0，或 HR ≤ 1 |
| | **不明确** | 其他情况 |

若苏格兰 Cox(ISUP + AI) 拟合失败或不收敛（AI 分级分数与 ISUP 几乎完全共线时可能发生），判定 2 不能为阳性：ΔC ≤ 0 记为阴性，否则记为不明确；所有 Cox 拟合的问题都记录在 RESULTS.json 的 cox_warnings 中。

苏格兰 ISUP 4 级只有 2 例、复发 27 次，区间会比较宽。结果原样报告，阴性也报告。
